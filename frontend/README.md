# Revix frontend

Bilingual English/Arabic interface built with Next.js, React, TypeScript, Tailwind CSS and next-intl.

Account forms are UI previews with local validation only. They do not authenticate users, send emails or save data. The backend directory is empty, and no environment variables are required.

From this directory, run npm install followed by npm run dev. Available checks: npm run typecheck, npm run lint, npm test and npm run build.
